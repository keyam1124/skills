# 日本語文書の読みやすさを整える

指定された文書や範囲をGemini 3.8 Flashへ送り、意図と内容を変えずに、自然で平易なビジネス向けの日本語に整える。対象テキストはGoogleに送信される。秘密情報や送信を許可されていない内容は送らない。

## 実行方法

認証済みのAntigravity CLI `agy` と `gemini-3.8-flash-medium` を使う。CLIの認証やモデルの利用には事前の設定が必要。`agy` がない場合や実行に失敗した場合は理由を伝えて停止する。無断で別モデルに切り替えない。

## 無料枠と複数ファイル

- 無料枠を前提とし、Antigravity CLIの `/usage` でモデルの利用状況と残り枠を確認する。上限や回復時刻は利用プランによって異なる。クレジットを使う設定が有効な場合は、無料枠のみを使うよう設定を確認する。
- 複数ファイルは並列送信せず、前の結果を確認してから次を送る。リクエスト開始時刻の間隔は少なくとも60秒とし、実際の制限や利用状況に応じてさらに空ける。60秒の間隔だけでは利用上限を回避できない。
- 利用上限のエラーが出た場合は処理を止め、利用状況と回復時刻を確認する。短時間の制限で枠が残っていると分かる場合に限り、必要な待機時間と上記の間隔を空けて最大1回だけ再試行する。残り枠がない場合や原因が不明な場合、再試行後も失敗した場合は利用者に伝え、枠の回復を待つ。
- タイムアウト時も処理済みで枠を消費した可能性がある。連続して再送せず、利用状況と処理対象を確認する。

## 文書を整える

1. 対象範囲と形式を確認する。Markdown構造、コード、URL、数値、固有名詞、条件、注意事項などは保持する。
2. スキルのディレクトリから、対象テキストを標準入力で渡す。

   ```sh
   python3 scripts/rewrite.py < input.txt > output.txt
   ```

   入出力ファイルは対象内容に適した場所に置く。入力が会話中の文章なら標準入力に渡す。スクリプトが失敗した場合、出力ファイルを修正文として使わない。
3. 原文と照合し、意味、事実関係、適用範囲、条件、断定の強さ、文書形式が保たれていることを確認する。問題のある変更は戻す。機械的な確認だけでは意味の一致を保証できない。依頼に応じて修正文を提示するか対象ファイルに反映する。

agyの待機上限は5分。エラー、空の応答、途中終了時は結果を採用せず、理由を伝える。長い文書は文脈を保てる単位に分け、全体の整合性を確認する。

実行方式を変更する場合は、[実行方式のDesign Memo](references/execution.md)を参照する。
